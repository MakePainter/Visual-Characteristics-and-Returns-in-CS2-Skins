# Processed data guide

`processed/` stores the **October 5, 2026 frozen snapshot**. The 17 analytical CSVs produced by `src/spectrum2_project.py` use the individual-skin window **2023-09-29–2026-09-28**; portfolio tables instead use common long-only endpoints **2023-09-29–2026-09-15**. The 18th CSV, `starting_price_diagnostic.csv`, is generated by `src/generate_figures.py` from the raw `spectrum2_master.csv`.

- `spectrum2_daily_prices.csv` and `spectrum2_daily_returns*.csv`: observed history and consecutive-day returns (no forward-filled skin prices).
- `spectrum2_financial_metrics*.csv` and `spectrum2_master*.csv`: individual-skin financial metrics and merged image/market features.
- `spectrum2_correlations*.csv`: Pearson/Spearman associations for visual characteristics and financial metrics.
- `spectrum2_portfolios*.csv`: all-17 benchmark, median-sorted High/Low buy-and-hold legs, and descriptive High-minus-Low spreads. **Common endpoints, but unequal intermediate observations.**
- `spectrum2_robustness_*.csv`: pooled 1st/99th percentile winsorization audit and metric comparison.
- `spectrum2_current_prices.csv`, `spectrum2_visual_features.csv`, and `spectrum2_risk_free_rates.csv`/`treasury_3month_risk_free.csv`: input snapshots and derived features.
- `starting_price_diagnostic.csv`: three raw-data bivariate starting-price/saturation/return correlations.

Raw observed-price results are primary; winsorized compounded returns are **synthetic** sensitivity measures. Future provider reruns may revise historical aggregates. Freeze the entire new analytical set together before rerunning `generate_figures.py`.
